# 二手房数据采集与可视化分析

武汉东湖高新区二手普通住宅挂牌样本可视化大屏。观察日期：2026-11-01（北京时间）；规则版本：20261101_final_v3。

终核纳入4012条、249个小区，地图展示740条有已知坐标系的详情匹配记录，按小区位置汇入约500米网格。挂牌单价中位数13038.5元/㎡，总价中位数135万元，面积中位数106.34㎡。价格为挂牌价。

数据来自默认排序前100页的6000次卡片展示，对应4943个不同编号；1057次为同编号再次展示。普通住宅口径不纳入931条（717条证据不足、214条不属于该类型口径）。同条件疑似重复仅标记保留，当前样本涉及55条。

页面提供5项指标、7张图表、组合筛选、小区搜索、分页明细和CSV导出。片区为平台标签；73条非标准标签合并显示为“其他平台标签”，明细及导出保留原标签。

静态HTML/CSS/JavaScript，无需安装依赖。GitHub Pages从main分支根目录发布。地图底图使用百度地图JSAPI 4.0，浏览器AK在map-config.js配置并限制Referer白名单。740条已定位记录均为BD09，直接用于小区标注；原WGS84近似网格编号继续用于分组和筛选，边界由百度SDK按WGS84坐标转换显示。通过HTTP本地服务或网站访问；地图需要网络，加载失败时其余指标与图表仍可使用。地图覆盖不代表全样本或全区库存。单日快照不展示跨日走势，散点R²为当前样本内拟合。

旧版武汉15片区2932条网页保留在Git历史提交 c4a1aa9a185f426ea5402f9df9f039fcaa5dc5b6，可按该提交恢复。

交互增强：片区、户型、朝向、单价区间、小区及地图网格可点击联动筛选；标签可单独取消。悬停即时详情、散点就近定位与明细高亮、地图缩放拖动/复位、明细三项数值升降序排序及减弱动画偏好均已实现。
