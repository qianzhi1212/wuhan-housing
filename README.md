# 二手房数据采集与可视化分析

大数据技术毕业设计阶段成果展示。武汉市二手房挂牌样本的基础清洗与描述性可视化，不提供房屋交易、推荐或预测服务。

观察日期：2026-10-29（北京时间）。原始采集3000条，覆盖15个平台区域；区域样本量由采集配额决定，不表示市场房源占比。价格为挂牌价。

对65组133条同条件记录，按规则剔除68条，最终保留2932条分析记录。同一来源、阶段、观察日内，区域、小区、户型、面积、朝向和总价完全相同的记录每组保留采集时间最新的一条。这是分析去重规则，不代表已确认物理住宅唯一性；原始备份和剔除明细保留在本地。

页面展示单日样本特征，不声称覆盖武汉全部房源，也不推断跨日走势。方差分析和线性回归尚未在本页面中作为已完成成果展示。

静态站点：index.html、style.css、app.js、data.js，无需安装依赖。可在GitHub Pages的main分支根目录发布，或通过任意本地静态服务器预览。页面只含展示字段，不含采集日志、运行状态、个人学号、数据库配置或本地路径。
